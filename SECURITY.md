# Security Policy

## Supported versions

This repository is an early UI skeleton. Treat the latest `main` as the supported line.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Email **security@askmian.com** with:

- A description of the issue
- Steps to reproduce
- Impact assessment if known

We aim to acknowledge reports within a few business days.

## Scope notes

- Integration stubs in `lib/` are intentionally incomplete.
- Do not test destructive scans against systems you do not own or lack written authorization for.
